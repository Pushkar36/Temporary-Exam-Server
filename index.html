⚙️ Core Capabilities

Everything You Need for
Secure Examinations

Built for institutions running practical coding exams at scale — with complete isolation, automation, and real-time visibility.

🐳

Docker Isolation

Each student gets their own isolated Docker container with a dedicated filesystem, networking stack, and compute resources. Zero cross-contamination guaranteed.

container · namespace
⚡

Auto Provisioning

Containers created in under 30 seconds via Jenkins CI/CD pipelines. Automated image pulling, network setup, and credential injection — zero manual steps.

jenkins · pipeline
🔒

Secure Environment

No cross-student interference, fully sandboxed code execution. Network egress policies, resource quotas, and read-only bind mounts enforce strict security.

sandbox · seccomp
📊

Live Monitoring

Real-time CPU, RAM and I/O activity tracking per container. Admin dashboard shows live metrics, connection status, and submission events as they happen.

metrics · websocket
🗑️

Auto Cleanup

Containers destroyed automatically after the exam ends. Submission archives are preserved to the database before teardown. No manual intervention needed.

ttl · teardown
🌐

Multi-Language

Pre-built Docker images for Python, Java, C++, Node.js and more. Custom images can be added by the admin with environment-specific toolchains pre-installed.

python · java · cpp
